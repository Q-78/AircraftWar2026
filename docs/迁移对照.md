# 实验二迁移对照

| 原工程 | Android 工程 | 处理 |
|---|---|---|
| `application/Main.java`、`Game extends JPanel` | `MainActivity`、`BaseGame extends SurfaceView` | 替换窗口入口与绘图线程 |
| `ImageManager` 的 `ImageIO.read` | `res/drawable` 与 `BitmapFactory.decodeResource` | 原图保留、资源名小写 |
| `HeroController` 鼠标监听 | `BaseGame.onTouchEvent` | 屏幕坐标换算为 512×768 游戏坐标 |
| `Game.action()` | `GameWorld.tick()` | 保留基础生成、射击、移动、碰撞、清理顺序 |
| `AbstractFlyingObject.crash()` | `GameWorld.Object.hits()` | 保留中心坐标、飞机纵向半高碰撞规则 |
| `EasyGame` 参数与敌机工厂 | `GameWorld` 常量和 `spawnEnemy()` | 沿用简单模式周期、概率、血量与速度 |
| Swing 音频、榜单、难度 UI、联网 | 暂未迁移 | 课程安排在后续实验 |
